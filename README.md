# Workout Calculator

A simple personal workout calculator for strength and endurance week targets.

## Disclaimer

This calculator is for general informational use only and is not medical, fitness, or professional training advice. Use your own judgment, consult a qualified professional before beginning or changing an exercise program, and stop if you feel pain or unsafe.

## Privacy

Entered workout numbers are stored locally in the user's browser using localStorage. They are not uploaded to GitHub or shared with other users.
